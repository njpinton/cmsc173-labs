submit the `.ipynb` on the course portal.

## How to use these

Click **Open in Colab** for the week you are on. Colab opens the notebook read-only
from this repository — use **File → Save a copy in Drive** before you start, or your
work is lost when the tab closes.

Nothing to install. Weeks 1–3 use NumPy only: you implement things by hand before
scikit-learn is introduced in week 4.

## Submitting

1. **File → Download → Download .ipynb**
2. Go to `https://portal.latarak.com/course/cmsc173/lab/<week>/submit`
3. Sign in with your student number and upload the file.

Re-uploading replaces your previous attempt; the most recent version is kept. Your
instructor issues your first password, which you change on first sign-in.
